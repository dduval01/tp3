# Contributing
Please follow these steps when contributing to this project.

## Workflow
1. Open an Issue to describe the task or problem.
2. Create a branch from `main`. Use `feat/` for new features, `fix/` for fixes or `docs/` for documentation.
3. Make small changes and write clear commit messages.
4. Check that the scripts still work if you change the code.
5. Open a Pull Request and link the Issue using `Closes #N` in its description.
6. Ask a teammate to review your changes.
7. Address any comments and wait for approval and passing CI checks before merging.

## Project rules
- Do not commit directly to `main`.
- Keep raw and processed data out of GitHub. Download the data from Borealis.
- Do not upload your Python environment or cache files.
- Update the README if your changes affect installation or execution.
- Keep documentation and figure labels in English.
- Follow the rules in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Reporting a problem
Include the command you ran, the error message and the steps needed to reproduce the problem. Mention your Python version when relevant.

## Commit messages
Use a short title that starts with a capital letter and has no final period. Explain what changed and add details if needed.
